# Үйлчилгээний гэрээ — урьдчилан тамгалсан PDF

СӨХ-тэй байгуулах гэрээг Хотолын тамга, захирлын гарын үсэг **урьдчилан
суусан** байдлаар PDF болгож бэлдэнэ. СӨХ нь зөвхөн өөрийн талын хоосон мөрийг
бөглөж, өөрийн тамга, гарын үсгээ зураад бидэн рүү буцаана.

## ⚠️ Энэ фолдер git-д ОРДОГГҮЙ

Репо **public**. Тамга, гарын үсгийн зураг нийтэд тарвал хэн ч Төгс Орчин ХХК-ийн
нэрээр хуурамч баримт үйлдэж чадна. `.gitignore`-д `/docs/contracts/*` гэж
бичсэн — зөвхөн энэ README л git-д ордог.

Тиймээс:

- `assets/*.png` — **бүү commit хий**, `public/` рүү бүү хуул.
- Гарсан PDF-үүд — мөн адил. СӨХ рүү шууд имэйл/мессежээр илгээнэ.
- Компьютер солих үед эх зургаас нь дахин үүсгэнэ (доор заавар).

## Ажиллуулах

**1. Тамга, гарын үсгийг зургаас ялгаж авах** (нэг удаа хийнэ):

```bash
node scripts/extract-seal.mjs <цаасны-зураг.jpg>
```

Тамгалж, гарын үсэг зурсан цагаан цаасыг сайн гэрэлтэй газар зурж авна.
Скрипт нь цаасны дэвсгэрийг ил тод болгож, бэхийг нь үлдээнэ. Зураг солигдвол
`scripts/extract-seal.mjs` доторх `CROPS` тохиргоог шинэ зурагт тааруулна.

**2. Тухайн СӨХ-ийн гэрээг PDF болгох:**

```bash
node --import ./scripts/lib/alias-register.mjs scripts/make-contract-pdf.mjs <sokh_id>
```

Сонголт: `--chairman="Б.Болд"`, `--register=9012345`, `--date=2026-08-24`,
`--out=<фолдер>`.

Гэрээний **текст, дүнг** энэ скрипт бичихгүй — `app/lib/contract/service-agreement.ts`
болон DB-ээс уншина (айлын тоо × тариф). Тиймээс сайт дээрх, Word дээрх, PDF
дээрх гурав үргэлж ижил нөхцөлтэй байна.

## Аппаас татах урсгал

Супер админ `/mng-ctrl/customers`-ээс тухайн СӨХ-ийн гэрээг нээхэд
(`contract_unlocked_at`) дарга нь `/admin/contract`-аас өөрийн гэрээгээ хараад
«Хэвлэх / PDF болгох» гэж татна.

Тэр урсгалаар татсан хувилбарт **тамга суудаггүй** — бэхний зураг серверт
байхгүй (репо public тул). Урьдчилан тамгалсан хувилбарыг одоогоор энэ
скриптээр гаргаж, гараар илгээнэ.

Сайтаас шууд тамгалсан PDF өгөхийг хүсвэл зургийг Supabase Storage-ийн **хаалттай**
bucket-д тавьж, сервер талаас service role-оор уншуулах хэрэгтэй. Тэр ажил
хараахан хийгдээгүй.
