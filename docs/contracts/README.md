# Үйлчилгээний гэрээ — урьдчилан тамгалсан PDF

СӨХ-тэй байгуулах гэрээг Хотолын тамга, захирлын гарын үсэг **урьдчилан
суусан** байдлаар PDF болгож бэлдэнэ. СӨХ нь зөвхөн өөрийн талын хоосон мөрийг
бөглөж, өөрийн тамга, гарын үсгээ зураад бидэн рүү буцаана.

## ⚠️ Энэ фолдер git-д ОРДОГГҮЙ

Репо **public**. Тамга, гарын үсгийн зураг нийтэд тарвал хэн ч Төгс Орчин ХХК-ийн
нэрээр хуурамч баримт үйлдэж чадна. `.gitignore`-д `/docs/contracts/*` гэж
бичсэн — зөвхөн энэ README л git-д ордог.

Тиймээс:

- `assets/*.png` — **бүү commit хий**, `public/` рүү бүү хуул.
- Гарсан PDF-үүд — мөн адил. СӨХ рүү шууд имэйл/мессежээр илгээнэ.
- Компьютер солих үед эх зургаас нь дахин үүсгэнэ (доор заавар).

## Ажиллуулах

**1. Тамга, гарын үсгийг зургаас ялгаж авах** (нэг удаа хийнэ):

```bash
node scripts/extract-seal.mjs <цаасны-зураг.jpg>
```

Тамгалж, гарын үсэг зурсан цагаан цаасыг сайн гэрэлтэй газар зурж авна.
Скрипт нь цаасны дэвсгэрийг ил тод болгож, бэхийг нь үлдээнэ. Зураг солигдвол
`scripts/extract-seal.mjs` доторх `CROPS` тохиргоог шинэ зурагт тааруулна.

**2. Storage-д байршуулах** (сайтаас татсан гэрээ тамгатай гарахын тулд):

```bash
node scripts/upload-seal.mjs            # шалгана
node scripts/upload-seal.mjs --commit   # хаалттай bucket-д байршуулна
```

**3. Тухайн СӨХ-ийн гэрээг PDF болгох** (гараар илгээх бол):

```bash
node --import ./scripts/lib/alias-register.mjs scripts/make-contract-pdf.mjs <sokh_id>
```

Сонголт: `--chairman="Б.Болд"`, `--register=9012345`, `--date=2026-08-24`,
`--out=<фолдер>`.

**Нэг ерөнхий хоосон загвар** (айлын тоо, дүн, Захиалагчийн мэдээлэл хоосон —
СӨХ өөрөө бөглөнө):

```bash
npm run contract:pdf -- --blank
```

Гэрээний **текст, дүнг** энэ скрипт бичихгүй — `app/lib/contract/service-agreement.ts`
болон DB-ээс уншина (айлын тоо × тариф). Тиймээс сайт дээрх, Word дээрх, PDF
дээрх гурав үргэлж ижил нөхцөлтэй байна.

## Аппаас татах урсгал (тамгатай)

1. Супер админ `/mng-ctrl/customers`-ээс тухайн СӨХ-ийн гэрээг **нээнэ**
   (`contract_unlocked_at`).
2. Дарга `/admin/contract`-аас гэрээгээ хараад «Хэвлэх / PDF болгох» гэж татна.
3. Гарсан PDF-д Хотолын **тамга, гарын үсэг суусан**, айлын тоо, дүн нь
   автоматаар бодогдсон байна. СӨХ зөвхөн улсын бүртгэл, и-мэйл, даргын нэрээ
   бөглөж, өөрийн тамгаа даран буцаана.

Тамгыг сервер нь Supabase Storage-ийн **хаалттай** `contract-seal` bucket-аас
уншина (`app/lib/contract/seal.ts`), инстанс тутам нэг удаа татаад кэшлэнэ.
Bucket нь `public: false` тул anon түлхүүрээр татагдахгүй — байршуулах скрипт
ажиллах бүрдээ үүнийг шалгадаг.

Зураг солих / шинэ компьютерээс сэргээх:

```bash
node scripts/extract-seal.mjs <цаасны-зураг.jpg>   # PNG дахин үүсгэнэ
node scripts/upload-seal.mjs --commit              # Storage-д шинэчилнэ
```

Сервер кэшийг цэвэрлэхийн тулд Vercel дээр redeploy хийнэ (эсвэл 1 минут
хүлээвэл алдаатай татсан тохиолдолд дахин оролдоно).

**Word хувилбарт тамга гарахгүй** — Word нь `data:` URI зураг харуулдаггүй.
Гарын үсэгтэй хувилбар хэрэгтэй бол PDF-ээр өгнө.
