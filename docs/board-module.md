# Цахим ТУЗ, Зөвлөлийн хэсэг

Миграц: `supabase-board-voting-migration.sql` → `supabase-board-members-migration.sql` (Supabase SQL editor-т гараар ажиллуулна).

## Гишүүд (`board_members`)
- `council`: `board` = ТУЗ, `audit` = Хяналтын зөвлөл.
- Гишүүнийг хоёр аргаар нэмнэ:
  1. **Админ → Оршин суугчид → «Зөвлөл» багана** (ТУЗ / Хяналт). `resident_id`-тай болж, апп-д «🏛 Зөвлөл» хэсэг нээгдэнэ.
  2. **Админ → Цахим ТУЗ → гараар нэмэх** (нэр, утас). `resident_id` байхгүй тул зөвхөн линкээр санал өгнө.
- Апп-ын эрх нээгдэх нөхцөл (`app/lib/council.ts`): `board_members.resident_id` = нэвтэрсэн оршин суугч **ба** `residents.phone` = тэмдэглэх үеийн `board_members.phone_number`.
  - Шалтгаан: бүртгүүлэх, профайлаас утас солих үед OTP байхгүй. Зөвхөн утсаар таньдаг байсан анхны хувилбарт өөр хүн гишүүний дугаарыг профайлдаа бичээд санхүүгийн баримт харж чадахаар байсан.
  - Тэмдэглэсэн мөрийг өөр утастай хүн «авбал» эрх нээгдэхгүй. Оршин суугчид хуудсанд «⚠️ утас зөрсөн · батлах» гэж харагдана.
- Дарга мөрийг урьдчилж тэмдэглэж болно. Тэр хүн бүртгүүлэхдээ тоотоо сонгож мөрийг авмагц эрх нь нээгдэнэ (`/api/auth/register` нь тоотоор тааруулна).

## Эрхийн ялгаа
| | ТУЗ | Хяналтын зөвлөл |
|---|---|---|
| Зөвлөлийн тайлан | харна | харна |
| Санал хураалт | харна + санал өгнө (санал өгөгчдийн жагсаалтад байвал) | харна + протокол |
| Санхүүгийн дэлгэрэнгүй | харна | харна |
| Гомдол / засварын явц | харна | харна |
| Зөвлөлийн чат | бичнэ | зөвхөн уншина |

## Санал хураалт
- SMS провайдер холбогдоогүй (`app/lib/sms.ts` нь stub) тул OTP код хүрдэггүй. 2026-11-03-аас гишүүн бүрт хувийн линк (`/vote/<id>?t=<invite_token>`) олгодог. Дарга линкийг өөрийн утаснаас SMS эсвэл Messenger-ээр илгээнэ.
- Апп доторх санал болон линкээр өгөх санал хоёулаа `castVote` (`app/lib/board-server.ts`)-оор дамжина.

## Санхүү (зөвхөн харах)
Сонгосон сарын нэхэмжилсэн ба цугларсан дүн, нийт авлага (нийлбэрээр, айлаар биш), орлого/зарлага (`budget_items`), төлөгдөөгүй өглөг, нөөц сангийн үлдэгдэл.

## Зөвлөлийн тайлан
- Админ: `/admin/board/reports`. Файл нь **private** `board-reports` bucket руу signed upload URL-аар шууд хуулагдана.
- Апп: `/sokh/<id>/council?tab=reports`. Хавсралтын signed URL 1 цаг хүчинтэй.

## Чат
`board_chat_messages`. Админ: `/admin/board/chat`. Realtime ашиглахгүй, хуудас харагдаж байх үед 10 секунд тутам polling хийнэ (Disk IO audit-ын шийдвэр).

## Хязгаарлалт
Push мэдэгдэл явахгүй (`push_subscriptions` нь оршин суугчаар биш, СӨХ-өөр бүртгэгддэг). Оронд нь нүүр хуудасны «🏛 Зөвлөл» товчин дээр уншаагүй тайлан болон санал өгөөгүй санал хураалтын тоо гарна.
