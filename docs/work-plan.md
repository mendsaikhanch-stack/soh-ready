# Ажлын төлөвлөгөө (жил + улирал)

Туршилт: 2026-11-11-нээс **зөвхөн ICTown (#2694)**. Сонирхолтой байвал бүх СӨХ-д нээнэ.

## Урсгал

1. **Дарга** `/admin/work-plan` хуудсанд жилийн төлөвлөгөө үүсгэнэ. Ажил бүрд улирал, ангилал, хариуцагч, төсөв, тайлбар оруулна.
2. **ТУЗ-д илгээх** дарахад ТУЗ-ийн гишүүд апп-ын «🏛 Зөвлөл → 📅 Төлөвлөгөө» табаас «✅ Батлах» эсвэл «✏️ Засвар хэрэгтэй» гэж санал өгнө. «Засвар хэрэгтэй» гэвэл сэтгэгдэл заавал бичнэ.
   - ТУЗ-ийн (board) гишүүдийн **олонх** баталбал автоматаар батлагдана. Хяналтын зөвлөл зөвхөн хардаг.
   - ТУЗ хурлаараа баталсан бол дарга хурлын огноо, тогтоолын дугаарыг бичээд «Хурлаар баталсан» гэж тэмдэглэнэ.
   - Засах шаардлагатай бол дарга «Буцааж засварлах» дарна. Дахин илгээхэд шинэ хувилбар болж, ТУЗ дахин санал өгнө. Хуучин саналууд түүхэнд хадгалагдана.
3. **Батлагдсаны дараа** оршин суугчдын апп-д «📅 Ажлын төлөвлөгөө» харагдана (Санхүү хэсэгт).
4. **Дарга гүйцэтгэл тайлагнана**: ажил бүрийн төлөв, гүйцэтгэлийн хувь, тайлбар, бодит зардлыг оруулж, зураг/баримт хавсаргана.
5. **ТУЗ дүгнэнэ**: тайлагнасан ажил бүрийг «Хийгдсэн / Дутуу / Хийгдээгүй» гэж үнэлнэ (дараа нь өөрчилж болно). Оршин суугчид үнэлгээний тоог харна, ТУЗ болон дарга гишүүдийн нэрийг харна.
6. Жилийн эцэст дарга **жилийн дүгнэлт** бичээд «Жилийг хаах» дарна.

## Техник

- Миграц: `supabase-work-plan-migration.sql`. Supabase SQL Editor-т гараар ажиллуулна. Дахин ажиллуулахад аюулгүй.
  - Хүснэгтүүд: `work_plans`, `work_plan_items`, `work_plan_files`, `work_plan_reviews`, `work_plan_ratings`.
  - Хувийн bucket: `work-plan-files`.
  - RLS бүгдийг хаана. Хүснэгтүүдэд зөвхөн API хандана.
- API: `/api/admin/work-plan` (дарга), `/api/work-plan` (оршин суугч, ТУЗ).
- Туршилтын жагсаалт: `app/lib/work-plan/shared.ts` → `WORK_PLAN_SOKH_IDS`.
  **Бүх СӨХ-д нээх** бол `isWorkPlanEnabled`-ийг `true` буцаадаг болгоно.
- ТУЗ-ийн гишүүнийг «🏛 Зөвлөл»-тэй ижил дүрмээр таньдаг (`app/lib/council.ts`): дарга оршин суугчийг ТУЗ гэж тэмдэглэсэн, утас нь таарч байх ёстой.

## Хийгдээгүй (дараагийн алхам)

- ТУЗ-д илгээх, батлагдах үед push мэдэгдэл явуулах.
- Бодит зардлыг санхүүгийн бүртгэлтэй (budget_items) автоматаар холбох.
- Оршин суугчид санал, сэтгэгдэл үлдээх.
- PDF / Excel-ээр татах.
