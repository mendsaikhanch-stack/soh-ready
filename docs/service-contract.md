# Үйлчилгээний гэрээ — Хотол ↔ СӨХ

Хэрэглэгч болсон СӨХ өөрийн дүнгээр бодогдсон гэрээгээ аппаасаа татаж авдаг.
Гэрээг **супер админ эрх нээсний дараа** л дарга харна.

## Урсгал

1. **Супер админ** → `/mng-ctrl/customers` → СӨХ-ийн карт → *Үйлчилгээний гэрээ*
   → **«Гэрээ татах эрх нээх»**. Тэр мөчид `contract_unlocked_at` тэмдэглэгдэж,
   гэрээний дугаар (`ХОТ-<он>-<СӨХ id>`) үүснэ.
   Айл ороогүй (0 айл) СӨХ-д эрх нээхгүй — дүн нь 0 гарах тул.
   *«Гэрээг харах»* товч нь эрх нээхээс өмнө ч гэрээг шинэ табд харуулна.
2. **Дарга** → `/admin/contract` (зүүн цэсний «📄 Үйлчилгээний гэрээ»).
   Даргын нэр, улсын бүртгэлийн дугаар, огноогоо бөглөөд:
   - 🖨 **Хэвлэх / PDF болгох** — хөтчийн хэвлэх цонхоор PDF болгож хадгална;
   - ⬇ **Word-оор татах** — `.doc` файл (Cyrillic бүрэн, Word-д засварлана).
   Эрх нээгээгүй бол «гэрээ бэлэн болоогүй» гэсэн мэдэгдэл + холбоо барих
   мэдээлэл гарна, гэрээний агуулга огт өгөгддөггүй (API 403).

## Гэрээний агуулга хаана байна

`app/lib/contract/service-agreement.ts` — **цорын ганц эх сурвалж**. Дэлгэц
дээрх урьдчилан харах хувилбар, татдаг Word файл хоёул эндээс үүснэ. 10 хэсэг:
гэрээний зүйл, хамрах хүрээ, төлбөр, оршин суугчийн хураамжийн урсгал, талуудын
эрх үүрэг, өгөгдлийн эзэмшил, хариуцлага, хугацаа/цуцлалт, бусад нөхцөл.

Дүнг `app/lib/platform-pricing.ts` тооцно (айл × тариф) — нэхэмжлэхтэй ижил тоо
гарна. Гэрээн дээр айлын тоо нь `residents` хүснэгтийн бодит мөрөөр бодогдоно,
`unit_count` (гараар бичсэн тоо) БИШ.

**Бөглөгдөөгүй талбар** (Хотолын регистр, банкны данс, захирлын нэр) нь
цэгтэй мөр болж хэвлэгдэнэ — гараар бөглөнө. `PROVIDER` тогтмолд утга оруулмагц
бүх гэрээнд автоматаар орно.

## Хийх ёстой миграц (гараар)

`supabase-service-contract-migration.sql`-ийг **Supabase SQL Editor**-т
ажиллуулна. `sokh_organizations`-д 3 багана нэмнэ:
`contract_number`, `contract_unlocked_at`, `contract_downloaded_at`.

Миграц ажиллаагүй бол юу ч унахгүй — `/mng-ctrl/customers` дээр «миграц
ажиллаагүй» гэж бичигдэж, эрх нээх товч 409 буцаана.
