## 1️⃣ Даргад — материалыг дагалдуулах бичвэр

```
Оршин суугчдад зориулсан ашиглах зааврыг бэлдлээ.

• zaavar.png — группт зургаар тавина
• zaavar.pdf — A4-ээр хэвлээд орц бүрийн самбарт наана

Энэ бол «юу хийж чадах вэ» гэдгийг харуулсан хуудас. Өмнөх QR
постертой хамт байвал бүртгүүлээд орхисон хүмүүс буцаж ирдэг.

Одоогийн байдлаар оршин суугчид өөрсдөө хараахан нэвтрээгүй байна.
Группт нэг тавиад, 3-4 хоногийн дараа сануулга тавихад хамгийн үр
дүнтэй байдаг.
```

## 2️⃣ Группт тавих бичвэр (`zaavar.png`-тэй хамт)

🏢 **Хүндэт оршин суугчид аа,**

Манай СӨХ **Хотол** системд шилжсэн. Утаснаасаа юу харж, юу хийж болохыг доор
жагсаалаа 👇

💵 **Төлбөр** — сарын хураамж, өрийн үлдэгдэл, төлсөн түүхээ хэзээ ч харна.
Тооцоо тулгахаар явах шаардлагагүй.
📢 **Зарлал** — СӨХ-ийн мэдээ, ус тасрах зэрэг зарлал утсанд тань шууд ирнэ.
🔧 **Засвар** — хүсэлтээ зураг хавсаргаж илгээгээд, явцыг нь хянана.
🛠 **Хийсэн ажил** — СӨХ-ийн хийсэн засварыг огноо, зурагтай нь харна.
💬 **Гомдол / Санал** — даргад шууд бичнэ.
🗳 **Санал хураалт** — хурлын шийдвэрт утаснаасаа санал өгнө.

**Хэрхэн орох вэ:**
👉 https://www.khotol.com/register?sokh=2690

1️⃣ **Тоот** хэсэгт хаалганыхаа дугаарыг бичнэ (1–129, урд нь тэг бүү нэм)
2️⃣ Нэр, утасны дугаараа бичээд өөрийн нууц үгээ тохируулна
3️⃣ Болоо

**📱 Утсандаа апп болгож хадгална уу:**
• **Android** — Chrome-ийн баруун дээд булангийн цэг гурвыг дарж «Нүүр хуудсанд нэмэх»
• **iPhone** — Safari-ийн доод талын хуваалцах товчийг дарж «Нүүр хуудсанд нэмэх»

Ингэвэл «Хотол» икон үүсч, дараа нь холбоос хайхгүй шууд нээгдэнэ.
**Апп татах шаардлагагүй.**

Тооцоондоо санал зөрвөл группт бичихийн оронд СӨХ-ийн даргад шууд хандаарай.

Тоотоо (1–129), нэр, утасны дугаараа бичээд нууц үгээ тохируулахад л болно.
Дараа нь хөтчийн цэснээс «Нүүр хуудсанд нэмэх» гэвэл апп шиг ажиллана.
Юм татах шаардлагагүй.

## 4️⃣ Асуулт гарвал (дарга хариулах)

| Асуулт | Хариу |
|---|---|
| «Уншуулахад юу ч болохгүй» | Хөтчөө нээгээд `khotol.com/register?sokh=2690` гэж шууд бичих |
| «Энэ тоот бүртгэгдсэн гэж байна» | Тухайн тоотод өөр хүн бүртгүүлсэн — дарга шалгаж, шаардлагатай бол салгана |
| «Нууц үгээ мартсан» | Дарга «Оршин суугчид»-аас нууц үгийг нь утасны дугаар болгож сэргээнэ |
| «Өрийн дүн буруу» | Даргад шууд хандах. Дарга «Оршин суугчид»-аас засна |
| «Аппаар төлбөрөө төлж болох уу» | Одоогоор БОЛОХГҮЙ — төлбөрөө урьдын адилаар төлнө, аппаас зөвхөн үлдэгдлээ харна |

## Файл дахин үүсгэх

Заавар хуудсыг засах бол `zaavar.html`-ийг биш, скриптийг засна:

```
node scripts/make-sokh-zaavar.mjs 2690
```

Скрипт нь нэг A4 нүүрэнд багтаж байгааг өөрөө шалгаж хэвлэдэг.
