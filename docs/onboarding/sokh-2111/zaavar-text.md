Бүртгүүлэх зарлалын текст тусад нь — [post-text.md](post-text.md).

> Нэвтэрсэн нь **1** — дарга өөрөө (9Б-34). Өөрөөр хэлбэл материал тараахаас
> өмнөх цэвэр эхлэл.
>
> ⚠️ 3 байртай: 9А (1–37) · 9Б (1–35) · 11 (1–40). Тоот давхцдаг тул
> **байраа заавал бичүүлнэ**.

## 1️⃣ Даргад — материалыг дагалдуулах бичвэр

```
Оршин суугчдад зориулсан материалыг бэлдлээ. 4 файл:

• poster.pdf — A4, орц бүрийн самбарт наана (бүртгүүлэх QR)
• post.png   — Facebook группт зургаар тавина
• zaavar.pdf — A4, «юу хийж чадах вэ» хуудас
• zaavar.png — группт зургаар тавина

Дараалал: эхлээд post.png + бүртгүүлэх бичвэрийг группт тавина.
3-4 хоногийн дараа zaavar.png + сануулгын бичвэрийг тавина.
Хоёулаа зэрэг тавихаар хүмүүс уншихаа больдог.

Хамгийн чухал: манай 3 байранд ижил дугаартай тоот байдаг тул
оршин суугч БАЙРАА (9А / 9Б / 11) заавал бичих ёстой. Бичвэр
болон самбар хоёуланд нь тусгасан.
```

## 2️⃣ Группт тавих бичвэр (`zaavar.png`-тэй хамт)

🏢 **Хүндэт оршин суугчид аа,**

Манай **Өрнөлт СӨХ** **Хотол** системд шилжсэн. Утаснаасаа юу харж, юу хийж болохыг доор жагсаалаа 👇

💵 **Төлбөр** — сарын хураамж (30,000₮), өрийн үлдэгдэл, төлсөн түүхээ хэзээ ч харна. Тооцоо тулгахаар явах шаардлагагүй.
🏦 **Банкны QR** — СӨХ-ийн Төрийн банкны QR аппад бий. Өөрийн банкны аппаараа уншуулахад мөнгө шууд СӨХ-ийн данс руу очно.
📢 **Зарлал** — СӨХ-ийн мэдээ, ус тасрах зэрэг зарлал утсанд тань шууд ирнэ.
🔧 **Засвар** — хүсэлтээ зураг хавсаргаж илгээгээд, явцыг нь хянана.
🛠 **Хийсэн ажил** — СӨХ-ийн хийсэн засварыг огноо, зурагтай нь харна.
💬 **Гомдол / Санал** — даргад шууд бичнэ.
🗳 **Санал хураалт** — хурлын шийдвэрт утаснаасаа санал өгнө.

**Хэрхэн орох вэ:**
👉 https://www.khotol.com/register?sokh=2111

1️⃣ **Байрны дугаар** хэсэгт байраа бичнэ — **9А**, **9Б** эсвэл **11**
2️⃣ **Тоот** хэсэгт хаалганыхаа дугаарыг бичнэ (урд нь тэг бүү нэм)
3️⃣ Нэр, утасны дугаараа бичээд өөрийн нууц үгээ тохируулна

⚠️ **Байраа заавал зөв бичнэ үү** — манай 3 байранд ижил дугаартай тоот байдаг.

**📱 Утсандаа апп болгож хадгална уу:**
• **Android** — Chrome-ийн баруун дээд булангийн цэг гурвыг дарж «Нүүр хуудсанд нэмэх»
• **iPhone** — Safari-ийн доод талын хуваалцах товчийг дарж «Нүүр хуудсанд нэмэх»

Ингэвэл «Хотол» икон үүсч, дараа нь холбоос хайхгүй шууд нээгдэнэ. **Апп татах шаардлагагүй.**

Тооцоондоо санал зөрвөл группт бичихийн оронд СӨХ-ийн даргад шууд хандаарай.

## 3️⃣ Богино хувилбар (Viber / орцны чат)

Хүндэт оршин суугчид аа,

Хотол системээс сарын хураамж, өрийн үлдэгдлээ харах, СӨХ-ийн банкны QR-аар төлөх, засварын хүсэлт илгээх, зарлалыг утсандаа авах боломжтой.

👉 https://www.khotol.com/register?sokh=2111

Байраа (**9А / 9Б / 11**), тоотоо, нэр, утасны дугаараа бичээд нууц үгээ тохируулахад л болно.
Дараа нь хөтчийн цэснээс «Нүүр хуудсанд нэмэх» гэвэл апп шиг ажиллана. Юм татах шаардлагагүй.

## 4️⃣ Асуулт гарвал (дарга хариулах)

| Асуулт | Хариу |
|---|---|
| «Уншуулахад юу ч болохгүй» | Хөтчөө нээгээд `khotol.com/register?sokh=2111` гэж шууд бичих |
| «Байраа юу гэж бичих вэ» | Яг `9А`, `9Б`, `11` гэж. Латин `9A`, жижиг `9а` ч болно — систем ижилтгэнэ |
| «Энэ тоот бүртгэгдсэн гэж байна» | Тухайн байр-тоотод өөр хүн бүртгүүлсэн — дарга «Оршин суугчид»-аас шалгаж, шаардлагатай бол салгана |
| «Нууц үгээ мартсан» | Дарга «Оршин суугчид»-аас нууц үгийг нь утасны дугаар болгож сэргээнэ |
| «Өрийн дүн буруу» | Даргад шууд хандах. Эх сурвалж нь Төрийн банкны тайлан (2026-09 эхэн) |
| «Нэр минь байхгүй / «19 тоот» гэж байна» | 4 тоотын эзний нэр бүртгэлд байгаагүй (9А-19, 9А-25, 9Б-23, 9Б-29). Бүртгүүлэхэд өөрийн нэр орно |
| «Аппаар төлбөрөө төлж болох уу» | Апп дотор төлөлт хийгддэггүй. Аппаас **СӨХ-ийн банкны QR**-ыг хараад банкны аппаараа уншуулж төлнө. Дарга дараа нь баталгаажуулна |
| «Төлсөн мөртөө өр хэвээр байна» | Дарга гараар баталгаажуулдаг тул 1-2 хоног зөрж болно. Удвал даргад хандах |

## Файл дахин үүсгэх

```
node scripts/make-sokh-qr.mjs 2111       # poster + post (бүртгүүлэх QR)
node scripts/make-sokh-zaavar.mjs 2111   # zaavar (ашиглах заавар)
```

Скрипт нь заавар хуудас нэг A4 нүүрэнд багтаж байгааг өөрөө шалгадаг.
Байрны нэр, тоотын хязгаар, айлын тоог DB-ээс уншдаг тул гараар засах шаардлагагүй.
