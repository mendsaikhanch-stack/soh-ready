### ⚠️ Demo дата САР бүр хуучирдаг

Төлбөр (`utility_bills`, `invoices`) болон Тайлан (`budget_items`) хуудас нь **яг
одоогийн он/сараар** шүүдэг. Өмнөх сарын дата үлдвэл дэлгэц **хоосон** харагдана —
Play-ийн шүүгч нэвтрэхэд апп эвдэрсэн мэт харагдах эрсдэлтэй.

Тиймээс шүүлтэд оруулахын өмнө (болон 2-3 сар тутам) дараахыг ажиллуул:

```bash
node scripts/refresh-demo-billing.js            # dry-run
node scripts/refresh-demo-billing.js --commit   # энэ сар + дараагийн 2 сар
```
