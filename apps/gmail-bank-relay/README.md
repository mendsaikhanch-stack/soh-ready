# Khotol Gmail Bank Relay

ХасБанкны **гүйлгээний имэйл мэдэгдлийг** Хотолын `POST /api/bank-sms` руу
дамжуулдаг Google Apps Script. Android SMS аппын
([`../android-sms-bridge`](../android-sms-bridge/README.md)) оронд ашиглана: Play
Protect-ийн хаалт, батарейн хязгаарлалт, утас асаалттай байх шаардлага байхгүй.

```
ХасБанк имэйл ─▶ Gmail ─▶ Apps Script (5 мин тутам) ─▶ POST /api/bank-sms (Bearer khsms_…)
                                                         └▶ parseBankSms (имэйлийн формат) → тулгалт
```

- Сервер тал, тулгалт SMS-тэй **ижил** (`app/lib/bank-sms/core.ts`). Нэг төхөөрөмжийн
  токен, `allowed_senders`-д банкны имэйл хаяг.
- `messageId = gmail:<message id>` — дахин илгээсэн ч давхардахгүй.
- Зөвхөн **орлогын** имэйл илгээнэ (зарлага — карт, POS — дамжихгүй). Сервер ч зарлагыг
  `debit_unverified` гэж хэзээ ч төлбөр болгодоггүй.
- Имэйлд дансны дугаар бүтнээрээ ирдэг; сервер `5006***029` маскаар хадгална. Маск нь
  төхөөрөмжийнхтэй таарахгүй (өөр данс) бол төлбөр болохгүй, шалгалт руу орно.
- Gmail хуурамч «From»-той (DMARC унасан) имэйлийг Spam руу хийдэг, хайлт Spam-ыг
  оруулдаггүй. Нэмэлт хамгаалалт: `auto_apply` унтраалттай үед дарга гүйлгээ бүрийг баталгаажуулна.

## Суулгах (нэг удаа, ~10 мин)

1. **Хотол ▸ Админ ▸ Банкны SMS гүйлгээ ▸ Дамжуулагч** — нэр «Gmail мэдэгдэл»,
   илгээгч = `XacInfo@xacbank.mn`, дансны маск `5006***029` →
   токен авна (нэг удаа харагдана).
2. Мэдэгдэл ирдэг Gmail-ээр нэвтэрч https://script.google.com ▸ **New project**.
   `Code.gs`-ийн агуулгыг бүхэлд нь хуулж тавина, нэрийг «Khotol bank relay».
3. ⚙ **Project Settings ▸ Script Properties**:
   `KHOTOL_TOKEN` = токен. (`BANK_FROM` — банк хаягаа сольсон үед л; анхдагч `XacInfo@xacbank.mn`.)
4. Дээд цэснээс `testConnection` сонгож **Run** → Google зөвшөөрөл асууна (Gmail унших,
   гадагш холбогдох) → зөвшөөрнө. Execution log: `200 {"ok":true,…}`.
5. `install` сонгож **Run** — 5 минут тутмын ажиллагаа үүснэ, сүүлийн 2 хоногийн
   имэйлийг нэг удаа илгээнэ.

Банкны имэйл өөр Gmail рүү ирдэг бол тэр данс дээр шүүлтүүр (from: банк → Forward to)
тохируулж, скриптийг хүлээн авах данс дээр суулгаж болно.

## Асуудал шийдэх

| Шинж | Арга |
|---|---|
| Админ дээр шинэ гүйлгээ гарахгүй | script.google.com ▸ **Executions** — алдаа байна уу. `testConnection` 401/403 бол токен солигдсон. |
| Executions хоосон | **Triggers** (⏰) — `relayBankEmails` 5 мин тутам байгаа эсэх; байхгүй бол `install`-ыг дахин ажиллуул. |
| SMS лог-д `sender_not_allowed` | Төхөөрөмжийн илгээгч `XacInfo@xacbank.mn` (эсвэл `BANK_FROM`)-той яг ижил эсэх. |
| `unrecognized_format` | Банк имэйлийн загвараа өөрчилсөн — `parseBankEmail`-ийг шинэчилнэ. |
